# SITRA — protótipo v12

Versão baseada no protótipo v11, atualizada conforme as decisões de estrutura, posicionamento e conteúdo definidas para a nova versão do site.

## Principais ajustes desta versão
- Home reorganizada com foco corporativo mais claro.
- Hero com slogan principal: “Saúde para quem trabalha. Sucesso para quem lidera.”
- CTA corporativo principal: “Solicitar uma proposta”.
- Menu principal consolidado em: Para empresas · Para você · Sobre a SITRA · Contato.
- Página Para Empresas reconstruída com: conformidade, diferenciais, soluções, presença no ambiente de trabalho, cuidado médico e benefícios.
- Exames → PCMSO → PGR + LTCAT como sequência principal de soluções.
- Comunicação mais forte sobre atendimento com hora marcada e avaliação médica cuidadosa.
- “Conhecemos o trabalho onde ele acontece” incorporado como diferencial.
- Página Para Você ampliada com consulta, acupuntura, práticas integrativas e saúde e sono.
- WhatsApp principal mantido em (31) 99914-5388.
- Identidade visual, logo e imagens da v11 preservados como base.
